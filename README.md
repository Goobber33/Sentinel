# Sentinel

A full-stack security monitoring and threat detection platform.

## Technology Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Infrastructure: Docker
- Testing: Pytest, Playwright

## MVP Features

1. Security event ingestion
2. Rule-based threat detection
3. Security dashboard
4. Alert investigation
5. Synthetic security event simulation
